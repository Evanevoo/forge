What is Forge?

Forge is a Windows desktop app that builds and signs React Native releases entirely on your machine — Android locally, iOS via free GitHub Actions. No cloud build queue. No per-build cost. No EAS dependency.

🤖 Android

Build and sign locally on Windows with Gradle. Full control, zero cloud cost.

🍎 iOS

Create certificates on Windows, compile on free GitHub Actions runners, submit to TestFlight from your desktop. No Mac required.

🏪 Submit Anywhere

Upload to Google Play or TestFlight directly. Version management, crash-reporter control, all built in.

💻 Windows-First

Designed for Windows React Native developers. GUI, not CLI. Offline-first. Never asks for your cloud creds.

🔐 Offline License

Ed25519 offline validation. No server, no phone-home, no internet required to use your license.

💰 One-Time Fee

Buy once, use forever. No subscription. Perpetual license key.
